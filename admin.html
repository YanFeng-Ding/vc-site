📄 贴入微信文章链接

每行一个链接。提交后自动触发即时同步（约 1-3 分钟发布上线），无需等每日巡检。

提交没成功？改用 GitHub 直接入队（境内网络推荐，10 秒搞定）
打开 GitHub 队列文件 ↗
把复制的行粘贴到 _queue.md 末尾 → 页面右下角 Commit changes。提交后约 1-3 分钟自动同步上线。
当前访问域名：　「提交并立即同步」= 入队 + 触发同步；「仅重跑队列」= 队列里有失败条目时手动重试。同步进度可在 GitHub Actions ↗ 查看。
